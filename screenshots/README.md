# Desktop screenshots

27 desktop images: 20 main pages/popups plus seven necessary validation, success, and empty-result states. No mobile screenshots.

Open index.html to browse. Pages use full-page captures; popup and empty-search images use a 1440 x 1000 viewport.

Account and selected authentication screens use browser-only demo API/session responses. Additional auth confirmations/errors are simulated: no accounts were changed and no emails were sent. See manifest.json for each image's route and capture details.
